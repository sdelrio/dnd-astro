A4, one PDF, selectable text with the site's own fonts. It is the same file the
publisher's `make handbook` writes and the repository keeps, so the edition you
download is the edition the house rules are at today.

## What is in it

- **A cover and a contents.** The contents lists the eight house-rule pages and
  the page each one starts on, not their section headings.
- **Eight chapters in sidebar order.** Each source page starts on a fresh sheet
  with its own title, so the book reads in the order the sidebar lists.
- **A footer on every sheet** carrying the chapter, the section it starts in and
  the page number, so "turn to twenty-two" means something.
- **Two 306px columns to a sheet**, because a 643px measure at 16px body text is
  a very long line for a page read at a table.

## What is not in it

There is no print-from-your-browser button, and that is deliberate. Offering one
would imply the artifact is equivalent to what a reader's own printer produces
from a screen page, which it is not: it has a cover, a contents, a page number on
every sheet and breaks placed by the author of each page. The web pages remain
the canonical source and are never replaced by the PDF.

## If the PDF is out of date

The repository keeps a small manifest beside the artifact: a content hash of the
eight house rules, the sheet count, and each sheet's page number and text hash. A
house rule edited without the artifact being regenerated fails the test suite, so
a stale book cannot reach this page through a quiet change.
